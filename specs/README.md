# Specs (Spec Kit)

Các spec được viết khi backend và app còn chung một repo, nên đường dẫn trong đó có dạng `backend/...` và `mobile/...`:
`backend/...` nay là thư mục gốc của repo này; `mobile/...` nay là thư mục gốc của hai repo app (iOS https://github.com/muoibuon/mstudent-ios, Android https://github.com/muoibuon/mstudent-android).
